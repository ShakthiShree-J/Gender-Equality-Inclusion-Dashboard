# Gender Equality & Inclusion Dashboard

An interactive **Power BI** dashboard analyzing gender equality and inclusion metrics across workforce participation, unpaid care hours, and higher education.

## Project Overview
This project explores disparities and trends across genders and sectors to highlight workforce representation, time spent on unpaid care work, and educational attainment.

## Tools & Technologies
* **Power BI:** Interactive visuals, slicers, and executive report layout (`GENDER Equality.pbix`)
* **Data Modeling & DAX:** Custom measures and comparisons across categories and dimensions
* **Microsoft Excel:** Source dataset used for building the dashboard (`Gender Equality dataset.xlsx`)

## Repository Files
* `GENDER Equality.pbix` – Interactive Power BI dashboard file
* `Gender Equality dataset.xlsx` – Dataset imported into Power BI
